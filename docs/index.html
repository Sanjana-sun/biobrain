Simulation · neuromorphic computing · energy harvesting

BioBrain

A spiking neural network powered by a glucose biofuel cell, with a regulator that scales its own firing rate to the charge left in a supercapacitor. It slows down instead of failing.

Sanjana Sri Injamuri · MS Computer Science, Northeastern University · source on GitHub

Everything on this page is computed live in your browser. The engine is a faithful port of the Python reference implementation — same equations, same parameters, same update order. Nothing here is a recorded number.

1. The problem

A biofuel cell delivers tens to hundreds of microwatts, and that output fluctuates with fuel concentration. A spiking network draws energy in bursts, because every action potential costs something. Put them together and you get a device that periodically runs out of charge mid-computation.

The established answers are all-or-nothing. Intermittent computing checkpoints state and halts until power returns. Power gating switches the load off below a threshold and on above another. Static DVFS picks one reduced clock rate and keeps it forever. Each treats energy as a binary condition or a constant chosen in advance.

Biological neural tissue does something different: it modulates activity. The question this project asks is whether a graded, closed-loop throttle — one that reads the reserve continuously and scales firing proportionally — buys anything that threshold or fixed-rate control cannot.

2. The mechanism, running

One 60-second simulation at 1 ms resolution, 64 leaky integrate-and-fire neurons. The glucose supply carries two famine dips; six brief high-demand events are the moments the device is supposed to respond to. Change the policy and watch the reserve.

3. Four policies, paired seeds

Every policy runs on the same per-seed environment with the same component noise, so differences are attributable to the policy alone. Intervals are percentile bootstrap, 2000 resamples, which matters because brownout is bounded in [0, 1] and often degenerate — a normal approximation is invalid there.

4. Why this is not just better tuning

The obvious objection is that a static duty cycle would match the regulator if you tuned it properly. So sweep it. Static DVFS has exactly one knob, and sweeping it reveals a discontinuity rather than a tradeoff curve.

5. What this model assumes, and where it is weakest

This is a simulation. No hardware has been built. The assumptions below are modelling conveniences, and the ones near the top are the ones most likely to change the conclusion rather than just the numbers.

  1. Peak cell power is set to 320 µW by default. The largest implanted enzymatic glucose cell in the literature delivered about 39 µW (Zebda et al., 2013); Rapoport et al. (2012) report roughly 180 µW/cm² as a peak areal figure. 320 µW therefore assumes a cell substantially better than any demonstrated implant. Drag the power slider down to 40 µW and the comfortable regime disappears — this is the single most load-bearing parameter on the page.
  2. Power and signal are treated as independent. The premise is that glucose is both fuel and input. But if output power depends on glucose concentration, then a weak signal means little power, exactly when computing may matter most. The model does not capture that coupling.
  3. The neuron model is idealised. Clean threshold, instantaneous reset, linear stationary leak. Real devices switch softly, drift with temperature, and vary from unit to unit.
  4. Energy delivery is instantaneous and scalar. Real supply arrives after a delay and is spatially structured. The supercapacitor has no self-discharge and no series resistance here.
  5. Device-to-device variation is zero. One controller setting is assumed to transfer. For printed or flexible substrates that is optimistic.
  6. The browser port is not bit-identical to the Python. NumPy's PCG64 cannot be reproduced here, so this page uses mulberry32 with Box–Muller normals. Structural results reproduce; static DVFS matches the reference to 0.05%, and power gating — the only stateful policy, whose switching times depend on exact threshold crossings — diverges by roughly 24%.

6. Reproducing this

git clone https://github.com/Sanjana-sun/biobrain
cd biobrain && pip install -r requirements.txt

python -m experiments.compare_policies   # 4 policies, 30 seeds, 95% CI
python -m experiments.robustness         # bootstrap CIs + baseline-fairness sweep
python -m experiments.tuning_cliff       # the discontinuity in section 4
python -m benchmark.run_benchmark        # FashionMNIST under intermittent power
